# 产品设计：让复盘进入后续练习

[← 返回项目](../README.md)

## 使用问题

棋局分析能够指出优劣，但使用者还需要研究当时的选择、确定值得反复练习的位置，并在以后重新遇到这些材料。棋谱屋围绕这条连续的使用过程组织功能。

## 产品流程与职责

| 层次 | 承接的工作 | 设计取舍 |
| --- | --- | --- |
| 棋局与测量 | 保存实战上下文、组织引擎评价 | 保留评价来源、历史与结果类型 |
| 报告与自由试走 | 查看实战和参考，继续研究局面 | 使用者可在棋盘上探索，保持研究位置与分支 |
| 自主收录 | 决定以后想练什么 | 不自动把收藏理解为掌握，也不代替使用者作选择 |
| 训练与复习 | 组织个人材料的反复使用 | 同时考虑新旧题、间隔、近期结果与来源分散 |
| 反馈与记录 | 连接本次表现与原始棋局 | 区分当前表现、参考变化和旧记录 |

## 为什么公开训练编排模块

这部分代码有清楚的输入与输出：输入候选材料及已有练习状态，输出本轮题目和编排依据。它可以独立运行，不依赖真实棋局、个人答题记录或引擎二进制，适合直接阅读和验证。

演示中的题目身份、时间和练习结果均为合成输入。演示说明当前规则如何作出选择，不用合成结果证明真实用户的学习收益。

## 当前范围

完整产品用于个人日常复盘与练习，也曾提供棋手试用。此仓库展示其产品逻辑和精选组件。后续新增的完整棋谱训练仍在独立迭代，不把在研入口列为这里已验证的交付结果。
