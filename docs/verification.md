# 精选代码包验证

验证日期：2026-11-04。运行环境：Python 3.12.14；页面脚本语法检查使用 Node.js 24.22.1。演示和测试只需 Python 标准库；Node.js 仅用于此次额外语法检查。

## 命令与结果

```text
python -B examples/schedule_demo.py --scenario all
python -B -m unittest discover -s tests -v
python -B examples/serve_schedule_lab.py
```

- CLI 正常完成五个合成场景。
- 18 项测试通过，其中 13 项是选题/演示行为检查，5 项是独立 HTTP 页面/API 检查。
- HTTP 测试使用系统分配的本机随机端口，完成后关闭服务；不访问完整产品端口。
- 交互页内联 JavaScript 通过 `node --check` 语法检查；实际浏览器视觉与点击验收结果见下方。
- 打包的 v7 文件 SHA-256 与原文件相同；v6 helper 的来源范围和打包 hash 记录在 `source-provenance.json`。

没有运行完整产品回归、棋力搜索或个人数据库迁移；本包也未包含这些组件。
